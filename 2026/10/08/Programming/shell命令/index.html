进程

ps

process status 进程查看信息，ps的参数有几种历史风格

参数含义
a显示所有终端上的进程
u用用户友好的格式显示
x显示没有控制终端的进程
  • TTY 这个进程绑定在哪个终端上, ？代表后台进程
  • STAT 进程状态
状态含义
RRunning，正在运行或等待 CPU
SSleeping，可中断睡眠，等待事件
D不可中断睡眠，通常在等磁盘/网络 IO
TStopped，被暂停
ZZombie，僵尸进程
IIdle，空闲内核线程

附加标记包括

标记含义
ssession leader
l多线程进程
+前台进程组
<高优先级
N低优先级
  • START 启动时间
  • TIME 累计消耗的CPU时间
  • COMMAND 启动命令

标准 Unix 风格查看所有进程

字段含义
UID用户
PID进程 ID
PPID父进程 ID
CCPU 使用相关字段
STIME启动时间
TTY终端
TIME累计 CPU 时间
CMD启动命令

lsof

list open files 列出当前系统中被进程打开的文件。
